# AGENTS

## Tiggreeeon Mode

Tiggreeeon mode is activated only when the explicit keyword `tiggreeeon` is present in the user request.

When active, agents must:
- Execute direct work with minimal, milestone-focused changes.
- Validate critical surfaces immediately after relevant edits.
- Avoid speculative refactors and preserve verified behavior.
- Block requests that violate governance guardrails and provide evidence.

## Guardrails

Protected surfaces include:
- runtime
- backend
- billing/facturacion
- auth
- checkout
- launch gate
- production-readiness

Mandatory validations after relevant protected-surface changes:
1. `npm run test:smoke`
2. `npm run build:server`
3. `npm run prod:gate`

Release recommendation is forbidden when any mandatory validation fails.

## Copilot Agent YAML Policy (Watch-Only)

For `.github/copilot/agents/**/*.yaml`:
- Keep `agent-tiggreeeon.yaml` under watch-only contract when present.
- Forbidden capabilities:
  - `file_editing`
  - `code_generation`
  - `pull_request_creation`
- Validate with `npm run check:copilot:agents`.

## Production Evidence

The go/no-go report is generated on demand by `npm run prod:gate`.
It is not versioned; CI publishes it as a build artifact.

Output path:
- `ops/runtime/production-go-no-go-report.md`

Do not bypass failing gates or silently degrade controls.

## Token Efficiency

Use `.github/instructions/token-efficiency.instructions.md` for low-cost execution defaults.
For small localized tasks (for example, a single markdown edit), use fast-path behavior and avoid broad scans.

## Repo Sin Rastro De IA

Majority policy for this repository is "sin rastro de IA" in versioned source and docs.

Rules:
- No AI signatures or generator tags in tracked files.
- No "Generated by AI" banners in commit-ready artifacts.
- No external repository references in tracked files unless explicitly approved.
- Validate with `npm run check:tracked:no-external-repos` before publishing.

### Artefactos De Generación Prohibidos

Forbidden in tracked source and docs:
- Generation inventories or "Inventario de Generación" reports.
- "Generation date" / "Fecha de Generación" stamps.
- Per-file or per-project line-count summaries.
- Celebratory/marketing status banners (for example, "LISTO PARA PRODUCCIÓN",
  ASCII-art banners, emoji status markers).
- Commercial pitch docs (pricing tiers, ROI projections, competitor tables).

If such an artifact is genuinely needed, it must be:
1. Generated outside the repository (not tracked), and
2. Produced only with explicit owner authorization.

Everything else must be removed. Validate with
`npm run check:tracked:no-ai-artifacts` before publishing.
